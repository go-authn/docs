saml — 置于联邦之前的服务提供方

go-authn/saml 是面向 RENATER 或 eduGAIN 等科研联邦的 SAML 2.0 服务提供方：已签名的元数据、AuthnRequest，以及在经过每项检查之后才读取的断言。

此人的身份提供方对他们说了什么？ 面向 RENATER 的 Fédération Éducation-Recherche 或 eduGAIN 等身份联邦的 SAML 2.0服务提供方：它读取联邦的已签名元数据，把人员送到其所属机构的身份提供方，并读回该提供方所说的内容。

go get github.com/go-authn/saml@v0.5.0

它是 authn-bridge 面向联邦的那一半，任何想要成为SAML SP 的程序都可以单独使用它。不包含：IdP、单点注销、artifact 绑定、已签名的AuthnRequest、属性查询、SAML 1.1。

Federation获取元数据，对照固定的证书验证它，并通过 Run 使其保持最新
ParseMetadata同样的验证，针对已在手中的文档
DiscoveryURL、Chosen将人员送到发现服务，并读回其所选择的 IdP
SP.Request通过 HTTP-Redirect 发送的 AuthnRequest，以及要保留的 Pending
SP.Accept提交到 ACS 的 SAMLResponse，被读取为 Assertion
Assertion.Subjectsubject-id，然后是 pairwise-id，然后是 eduPersonPrincipalName，然后是 eduPersonTargetedID，然后是持久 NameID——绝不是邮件地址
SP.MetadataSP 自己的元数据，用于向联邦注册

示例

发现和请求，其中一个 IdP 为手工描述：

package main

import (
	"fmt"
	"net/url"

	"github.com/go-authn/saml"
)

func main() {
	// One IdP, as a federation's metadata would describe it.
	idp := &saml.IdP{
		EntityID: "https://idp.univ-example.example/idp/shibboleth",
		SSO:      "https://idp.univ-example.example/idp/profile/SAML2/Redirect/SSO",
		Scopes:   []string{"univ-example.example"},
	}
	md := &saml.Metadata{IdPs: map[string]*saml.IdP{idp.EntityID: idp}}

	sp := &saml.SP{
		EntityID:   "https://app.example.org/saml",
		ACS:        "https://app.example.org/saml/acs",
		Federation: md,
	}

	// Send the person to the discovery service, then read back what it chose.
	d, _ := saml.DiscoveryURL("https://discovery.renater.fr/renater", sp.EntityID, "https://app.example.org/saml/chosen")
	fmt.Println(d)

	_, err := saml.Chosen(url.Values{"entityID": {"https://idp.attacker.example/idp"}}, md)
	fmt.Println(err)
	chosen, _ := saml.Chosen(url.Values{"entityID": {idp.EntityID}}, md)

	// The AuthnRequest, over HTTP-Redirect. Keep p, keyed by the RelayState,
	// and hand it to sp.Accept at the ACS.
	to, p, err := sp.Request(chosen, "s1", saml.Options{AuthnContext: []string{"https://refeds.org/profile/mfa"}})
	if err != nil {
		panic(err)
	}
	u, _ := url.Parse(to)
	fmt.Println(u.Host, u.Query().Has("SAMLRequest"), u.Query().Get("RelayState"), p.IdP, p.AuthnContext)

	// RelayState is limited to 80 bytes, and refused beyond that.
	_, _, err = sp.Request(chosen, string(make([]byte, 81)), saml.Options{})
	fmt.Println(err)
}

在实际服务中，元数据来自联邦，而响应到达ACS：

package main

import (
	"context"
	"crypto/rsa"
	"crypto/tls"
	"crypto/x509"
	"encoding/pem"
	"log"
	"net/http"
	"os"

	"github.com/go-authn/saml"
)

func main() {
	ctx := context.Background()

	// The federation's metadata signing certificate, downloaded ONCE and
	// checked against the fingerprint the federation publishes.
	fed := &saml.Federation{
		URL:  "https://pub.federation.renater.fr/metadata/fer/idps.xml",
		Cert: readCert("/etc/app/metadata-signature-2026.pem"),
	}
	if err := fed.Refresh(ctx); err != nil {
		log.Fatal(err)
	}
	go fed.Run(ctx, func(err error) { log.Print(err) })

	pair, err := tls.LoadX509KeyPair("/etc/app/saml.crt", "/etc/app/saml.key")
	if err != nil {
		log.Fatal(err)
	}
	sp := &saml.SP{
		EntityID:   "https://app.example.org/saml",
		ACS:        "https://app.example.org/saml/acs",
		Key:        pair.PrivateKey.(*rsa.PrivateKey), // assertions arrive encrypted to it
		Cert:       pair.Leaf,
		Federation: fed,
	}

	http.HandleFunc("/saml/acs", func(w http.ResponseWriter, r *http.Request) {
		p := pendingFor(r.PostFormValue("RelayState")) // what Request returned, from the session
		a, err := sp.Accept(r.PostFormValue("SAMLResponse"), p)
		if err != nil {
			log.Print(err) // for the log, not for the browser
			http.Error(w, "refused", http.StatusForbidden)
			return
		}
		id, from := a.Subject()
		log.Printf("%s (%s) from %s", id, from, a.IdP.EntityID)
	})
	log.Fatal(http.ListenAndServeTLS(":443", "/etc/app/tls.crt", "/etc/app/tls.key", nil))
}

func readCert(path string) *x509.Certificate {
	b, err := os.ReadFile(path)
	if err != nil {
		log.Fatal(err)
	}
	blk, _ := pem.Decode(b)
	if blk == nil {
		log.Fatal("no PEM block in ", path)
	}
	c, err := x509.ParseCertificate(blk.Bytes)
	if err != nil {
		log.Fatal(err)
	}
	return c
}

// pendingFor is the caller's session store.
func pendingFor(relayState string) saml.Pending { return saml.Pending{} }

它拒绝什么，以及原因

元数据：

原因
不是由固定的证书签名证书是一个参数，绝不与元数据一同获取：与它所担保的文档通过同一渠道到达的密钥，什么也担保不了
超过其 validUntil，或没有该字段永不过期的已签名文档，意味着永远不会结束的密钥泄露。刷新失败时保留上一份良好的副本，直到该副本过期
有效期距今超过 28 天Federation.MaxValidity 可更改该界限；负值则取消它
比正在使用的副本更旧回滚：签名有效，并且可能带有此后已被吊销的密钥
通过 http:// 从环回之外的任何地方获取签名可以发现更改，却发现不了扣留新文档的路径

元数据中 IdP 的证书之所以受信任，是因为联邦的签名指名了它；不检查其日期，因为 IdP 证书常常是自签名且已过期的。

响应在 Accept 时检查。下面的每项拒绝都会作为错误返回给调用方，供服务器的日志使用：

原因
没有任何签名，或使用 SHA-1 签名saml-profiles 4.1.4.5：通过 POST 时断言必须经过签名。Shibboleth IdP 默认对 Response 签名；两者皆可接受
多于一个断言这正是已签名的断言与未签名的断言同时到达而读取了错误那个的方式（CVE-2022-41912）
签名所覆盖范围之外的任何内容绝不读取：只读取根据签名所摘要的字节重建的元素
位于 IdP 的 Scopes 之外的带 scope 标识符丢弃：否则任何 IdP 都可以断言 alice@another-university.example
没有已验证签名覆盖的 AES-CBC 密文甚至不解密：未经认证的 CBC 是填充预言机。完全不接受 RSA PKCS#1 v1.5 密钥传输；接受 AES-GCM 和 RSA-OAEP
另一个 audience、ACS 或请求；未经请求的响应；超过一小时的请求saml-profiles 4.1.4.3
已经使用过的断言持有者断言属于持有它的任何人
它不理解的条件saml-core 2.5.1：该断言随后为 Indeterminate
要求 MFA（Options.AuthnContext）时返回了密码IdP 可能忽略该请求
使用 ForceAuthn 时，早于请求的 AuthnInstantIdP 重用了被要求不要重用的会话

默认的重放缓存是单个进程的内存

SP.Replay 默认为 NewMemoryReplay()。负载均衡器之后的多个实例会各自接受同一个断言一次，而重启会清空它。请基于共享存储实现 Replay；其 Use 必须是原子的。

测试建立在它之上的程序：samltest

github.com/go-authn/saml/samltest（自 v0.5.0 起）是一个联盟和一个 IdP，用于测试建立在本包之上的程序，例如位于联盟前面的 OpenID 提供方（go-authn/bridge），或位于其后的程序（go-llmflow/bench）。它是纯 Go：使用它不需要 xmlsec1。

fed, _ := samltest.NewParty("federation")
key, _ := samltest.NewParty("idp")
idp := &samltest.IdP{EntityID: "https://idp.univ-ex.example/idp/shibboleth",
	Scope: "univ-ex.example", SSO: srv.URL + "/SSO", Signer: key}
md, _ := (&samltest.Federation{Signer: fed, IdPs: []*samltest.IdP{idp}}).Metadata(24 * time.Hour)
// serve md; pin fed.Fingerprint() in the program's configuration
srv.Config.Handler = idp.Handler(spEntityID, acsURL, spCert, func(user, pw string) ([]samltest.Attribute, bool) {
	return []samltest.Attribute{{Name: samltest.EPPN, Values: []string{user + "@univ-ex.example"}},
		{Name: samltest.Entitlement, Values: []string{"grp-alpha"}}}, pw == "secret"
})
  • 元数据：由联盟密钥签名的 EntitiesDescriptor，包含每个 IdP 的 scope、显示名称、签名证书和HTTP-Redirect SSO 地址。
  • 响应：IdP.Response 接收带有请求 ID、受众、ACS 和属性的 Assertion。Response 使用 RSA-SHA256、独占 c14n、enveloped 方式，在 Issuer 之后签名。断言用 SP 的证书以 AES-128-GCM 和RSA-OAEP MGF1-SHA1（Shibboleth IdP v5 的默认值）加密；当 EncryptTo 为 nil 时，断言本身以明文签名。
  • 登录：IdP.Handler 针对 AuthnRequest 显示用户名和密码表单，并以向 ACS 提交 SAMLResponse 和RelayState 的表单作答；测试的 HTTP 客户端像浏览器脚本那样提交它。

它的输出由并非它的作者的各方来判定：xmlsec1 验证元数据和两种 Response 并解密断言（缺少 xmlsec1时该测试会说明并跳过；设置 SAML_REQUIRE_JUDGE=1 时则失败），而本包的 SP 接受它们，并拒绝被篡改、被重放或由联盟未列出的密钥签名的版本。密钥在每次调用时生成，所以这里的任何东西都不应用于生产环境。

它对照什么检查

  • RENATER 自己的元数据，即 RENATER 于 2026-09-29 签名的版本，位于testdata/fer-idps.xml.gz，其证书对照 RENATER 发布的SHA-256 指纹检查。读取全部 343 个 IdP；改写某个 Location 的主机会被拒绝。各架构通道（包括 s390x）也会验证该签名。
  • xmlsec1 根据模板签名并加密套件中的每个响应：GCM 和 CBC、使用 SHA-1 和 SHA-256 的 RSA-OAEP、Response 签名、断言签名、两者皆签。Linux 测试通道、竞态检测器和覆盖率通道安装它并设置 SAML_REQUIRE_JUDGE。
  • crewjam/saml 的 IdP 在单独的 CI 作业中针对此 SP 的 AuthnRequest 写出完整的响应（interop/crewjam，自成一体的模块，不在已发布的模块中）：RSA-SHA256 加 AES-128-CBC 且 Response 已签名的响应被接受；其默认的 RSA-SHA1 被拒绝；去掉 Response 签名的同一个 CBC 断言在解密之前就被拒绝。

覆盖率通道的下限是 92%。
